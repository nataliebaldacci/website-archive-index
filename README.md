# Website archive index

Clickable lists of archived (Wayback Machine) pages, images and videos for the Johnson Chiropractic Group, Dr. Peter Levy and NutraGen websites, plus website links for other chiropractors. Built 2026-10-26.

Live: https://nataliebaldacci.github.io/website-archive-index/

- `pages.html`: every page laid out by each site's own menu, with first saved, last saved, last updated, and every saved version.
- `media.html`: every image and video file saved per site.
- `doctors.html`: other chiropractors' websites, about pages and Wayback history.

Source: Internet Archive CDX capture lists and archived home-page menus.
