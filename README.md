# Website archive index

Clickable lists built 2026-10-26 from public records and the Internet Archive (Wayback Machine).

Live: https://nataliebaldacci.github.io/website-archive-index/

- `pages.html`: every page of the Johnson Chiropractic Group, Dr. Peter Levy and NutraGen websites, by each site's own menu, with first saved, last saved, last updated and every saved version.
- `media.html`: every image and video file saved for each site.
- `doctors.html`: every chiropractor and NMR practitioner we hold a website or saved page for, with Wayback history.
- `nmr.html`: Neuromuscular Reeducation (NMR): Dr. Levy's sites and videos, every seminar and CE session found, practitioners, testimonials, trademark record and outside sources.
- `testimonials.html`: every patient testimonial and athlete success story Dr. Johnson published on his websites, with the archived pages.
- `contracosta.html`: Contra Costa chiropractors (DCA roster), shared offices, practitioners under one roof (NPI), residences of record (no street addresses), unincorporated medical-dental parcels, and maps. Interactive map: https://nataliebaldacci.github.io/contra-costa-chiropractors-map/

Emails, phone numbers and residential street addresses are left out.
